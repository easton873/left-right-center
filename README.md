# Left, Right, Center

A single-page browser version of the dice game, playable against 1–7 computer players.

Play: `https://easton873.github.io/left-right-center/` (after enabling GitHub Pages).

## Hosting on GitHub Pages
Settings → Pages → Source: "Deploy from a branch", pick the branch containing `index.html` and the `/ (root)` folder.

## Rules
Everyone starts with 3 tokens and rolls one die per token (max 3). L passes a token left, R passes right, C puts it in the center, a dot keeps it. Players with no tokens skip their turn but can receive tokens. Last player holding tokens wins.
